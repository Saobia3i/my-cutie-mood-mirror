# Mood Mirror 🐱✨

Your facial expression, mirrored live onto a cute cartoon cat.
Allow camera access and start making faces -- smile, look surprised,
squint sleepily, furrow your brow, or pout, and watch the cat react
with matching particle effects and gentle messages.

Built with MediaPipe Face Landmarker (rule-based expression detection,
no training data needed) + OpenCV + Gradio.
